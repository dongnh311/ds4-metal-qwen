# V4.1 PR #1073 Streaming Measurement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure whether antirez/ds4 PR #1073 ("Speed up DeepSeek V4.1 Flash on Metal", head `3d3c83bb`) speeds up DeepSeek-V4.1-Flash Q2 SSD-streaming decode on this M5 Pro 64 GB box compared with our `develop`, and decide from the numbers whether to integrate it.

**Architecture:** Three binaries are built in their own detached worktrees: **D** = `origin/develop` (our runtime), **P** = PR #1073 head as-is, **M** = `antirez/main` `0aaea5a` (the PR's base). The existing interleaved A/B driver `speed-bench/v41/ab.py` gets per-side binaries and a "plain" mode without diagnostics env, so both binaries run exactly the same command and environment. One GPU window runs a greedy identity check and three A/Bs; the results and the decision go to `speed-bench/v41/pr1073-20261002/RESULTS.md`. Nothing from #1073 is merged in this plan.

**Tech Stack:** Python 3 (`unittest`), `ds4-bench` / `ds4` CLI, git worktrees, `download_model.sh`, AI-Gateway `server-power.sh`.

**Spec:** `docs/V41_64GB_BUILD.md` (DoD 2 measurement protocol) plus the user's decision on 2026-10-02: "đo trước" (measure #1073 before any integration), starting only after the Mac16-DS4-Metal-Ornith session finishes its measurement.

## Global Constraints

- No GPU use (Metal tests, `ds4`, `ds4-bench`) while another session holds the GPU. Start the window only after Mac16-DS4-Metal-Ornith has finished, the Qwen session has no window open, and the user approves the gateway pause.
- The gateway is stopped and started only with `~/Documents/GitHub/AI-Gateway-MLX/scripts/server-power.sh off` / `on`. Never `kill -9` a Metal process: a SIGKILLed Metal process can leave its GGUF unopenable until a reboot.
- Keep at least 40 GiB free on the data volume at all times; macOS swap lives there.
- Speed is judged only by interleaved A/B (order A, B, B, A on fresh processes), never against a stored number.
- Model: `DeepSeek-V4.1-Flash-Q2.gguf`, 365,713,686,528 bytes, SHA-256 `1ce6a8f8806205c13330d7ca287bd198331dc5ca35ccc5d8a9a92a188a6f6f42`, stored in `~/orca/workspaces/ds4-metal-data/gguf/`.
- Measurement point (DoD 2): `switch` prompt, ctx 8192, 512 generated tokens, `--teacher-forced-decode`, `--ssd-streaming`.
- Code, comments, commits and docs in English. Raw outputs go under `~/orca/workspaces/ds4-metal-data/v41-pr1073/20261002/`; only the A/B JSONs and `RESULTS.md` are committed.
- Do not run the Qwen regression gate (it belongs to the Qwen session). This plan changes only Python tools, no shared runtime code.
- DSpark is out of scope: in PR #1073, `ds41_draft_init` returns false when `g->streaming`, so it cannot run under `--ssd-streaming`.

## Review Focus

- A rerun in the same `--out` reuses a finished run that was produced by a different binary: the ratio becomes meaningless. A reused run must be refused unless its recorded binary matches (Task 1, `test_reuse_refuses_other_bin`).
- Diagnostics env reaches only one binary (`DS4_V41_DECODE_PROFILE` exists only in D), or leaks in from the caller's shell: biased ratio. Plain mode must strip every `phase0.ENV` key, inherited or not (Task 1, `test_plain_strips_inherited_profile_env`).
- The two binaries size the auto cache differently, so an auto-cache ratio mixes cache size with kernel speed. Record `cache_experts` per arm and also run a fixed 24 GB A/B (Task 4, ab3).
- The PR binary may fail to open V4.1 Q2 streamed on 64 GB (memory plan too large, or the flag set differs). Each arm's identity run doubles as a load smoke test, and a failure is a result to record, not something to work around (Task 4, Step 3).
- Runs contaminated by another ds4 process or by swap. `phase0` marks them; a contaminated A/B is rerun once under a new label, and is reported as such if it is contaminated again (Task 4, Step 5).

def profile_mismatch(row_env, plain):
    """True when a reused run's diagnostics env differs from the mode asked for
    now: plain runs carry none of phase0.ENV, default runs carry all of it."""
    present = [k for k in phase0.ENV if k in row_env]
    return bool(present) if plain else len(present) != len(phase0.ENV)
